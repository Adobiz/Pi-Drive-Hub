# PI 网盘

**干净 · 无广告 · 多网盘桌面客户端**

一个用 Flutter 构建的 Windows 桌面网盘客户端，以**官方客户端接口**接入多个网盘，
提供干净的界面、无广告打扰、无多余图标，支持官方登录页扫码/账密登录、全目录操作。

</div>

---

## ✨ 特性

- 🧹 **干净无广告**：无任何广告位、无多余图标、无启动弹窗
- 🔗 **多网盘支持**：百度网盘 / 夸克网盘 / 123云盘（统一抽象，易扩展）
- 🔐 **官方登录页登录**：内嵌官方登录页扫码 / 账密登录，凭据本地加密存储（Windows DPAPI）
- 📂 **全目录操作**：浏览、上传、下载、新建文件夹、重命名、删除、移动、搜索（不受官方 /apps 目录限制）
- ⏬ **下载能力**：分片下载、断点续传、并发控制（按账号会员等级自动调整）
- ⏫ **上传能力**：多协议上传（百度表单 / 夸克 OSS / 123 S3）
- 🎨 **轻量界面**：Material Design，启动快、内存占用小

## 📦 支持网盘

| 网盘 | 登录方式 | 说明 |
|------|---------|------|
| 百度网盘 | 官方登录页（扫码/账密） | 客户端协议，任意目录，SVIP 自动并发 |
| 夸克网盘 | 官方登录页（扫码） | 客户端协议，OSS 分片上传 |
| 123云盘 | 账号密码 | 客户端协议，S3 上传 |

> 注：各网盘均通过**非官方客户端协议**接入（逆向自开源项目如 BaiduPCS-Go、alist），
> 仅用于个人学习与技术交流，请遵守各网盘服务条款。

## 🚀 快速开始

### 环境要求

- Flutter 3.29+ stable / Dart 3.7+
- Windows 10/11（桌面端）
- Visual Studio 2022（含 C++ 桌面开发）、CMake
- `nuget.exe` 需在 PATH（`flutter_inappwebview_windows` 构建依赖）

### 构建运行

**一条指令构建**（Windows，需 Flutter 环境 + nuget 在 PATH，详见下方）：

```bat
build.bat              :: 构建 release（中文，默认）
build.bat en           :: 构建 release（英文界面）
```

> ⚠️ 工程路径必须为纯英文（中文路径会导致编译失败）。

## 🏗️ 项目结构

```
lib/
├── core/
│   ├── models/            # 文件/账号模型
│   ├── providers/         # CloudProvider 抽象 + 注册中心
│   ├── storage/           # 凭据加密存储（DPAPI）
│   └── state/             # 全局状态 + 下载/上传管理器
├── providers/
│   ├── baidu_client/      # 百度网盘（客户端协议）
│   ├── quark/             # 夸克网盘
│   └── pan123/            # 123云盘
└── ui/
    ├── login_page.dart    # 登录页（通道选择）
    ├── file_browser_page.dart  # 文件浏览
    └── download_page.dart # 传输管理
```
