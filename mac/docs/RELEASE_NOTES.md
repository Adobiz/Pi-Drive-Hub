# PI 网盘 macOS 1.0.0 开发预览

> 发布草稿：当前本地安装包没有 Developer ID 分发签名或公证，尚未完成真实服务、全新机器及 Intel 实机验收。若公开测试附件，请保留 UNSIGNED 文件名并标记为 pre-release。完成正式验收后再修改状态。

## 功能

- 百度网盘、夸克网盘与 123 云盘的文件浏览、搜索、上传和下载。
- 多窗口与独立网盘标签页：⌘N 新窗口，⌘T 新标签页，Control + Tab 切换。
- 圆润云朵菜单栏、实时传输任务及最近 60 秒上传/下载曲线。
- 关闭标签页保留后台任务，右上角仅保留「＋」入口。
- 统一的圆角云朵 Logo；提供 DMG 拖入 Applications 的安装方式。

## 修复与检查

- 修复传输刚入队时关闭窗口可能提前销毁引擎的问题。
- 关闭标签页后，迟到的登录回调不再切换账号或取消后台任务。
- Keychain 拒绝访问或凭据异常时返回可恢复的登录失败。
- 防止登录 Cookie 轮询重叠、初始化未完成时读取旧状态及页面关闭后重复回调。
- 保留传输取消、同名文件保护、分片完整性验证及 Cookie 域范围限制。
- 46 项自动化测试、14 项原生离屏断言通过；macOS universal 构建及本地安装包结构检查通过。

## 限制

- 本轮未使用真实账号验证服务端协议；不保证绕过限速、会员限制或风控。
- 任务只保存在内存；退出、崩溃或升级后不保证续传。上传继续会重新开始。
- 同一网盘多账号同时登录尚未验收；Keychain 按服务保存一份凭据。
- Intel、较低版本 macOS、睡眠唤醒和长时间插件生命周期仍需实机验收。
- 没有自动更新功能，后续版本通过 GitHub Release 下载。

升级前完成旧版本传输并退出旧版。应用程序安装包是 Release 附件中的 DMG 或应用 ZIP；自动附加的 Source code ZIP 供开发者使用。
